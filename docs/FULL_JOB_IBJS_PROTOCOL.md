## Implemented pure interfaces and evidence

`State(tables, rows, cardinality)` stores a canonical table tuple, at most1000 complete bag dictionaries `{table: projected_row}` and a nonnegative Fraction. Bag identity is all participating entity IDs. Repeated FK/title IDs across different bag vectors remain distinct; inconsistent values for the same entity ID and duplicate full vectors are rejected. `base_state(query, table, raw)` validates every raw integer/NULL row before filtering, including rows that predicates reject. `draw_base(...)` calls only the pinned pure SRS ID sampler, with the same seed stream but new independent callback work; it returns the filtered state and preserves the complete unfiltered trace. It never adopts prior SRS sample data.

`extend(query, state, added, probe, budget, trace, n=1000, rng=None, check=...)` performs Alg1-style rank expansion. Its input has its own1000-row bound; n bounds the output, permitting smaller toy output capacities. The check hook is for a future source-bound shared query clock/resource gate, not a parent-validation bypass. It runs around callbacks and within rank/materialization loops. Same-origin returned IDs must increase strictly with selected offsets; this consistency check does not independently prove an absolute live SQL rank. That proof still needs the fixed future SQL/locked snapshot/complete receipt contract. Count/kth callback attempts are logically charged at callback dispatch even when they fail or return truncated results; their unused reserved capacity alone is refunded. Physical SQL calls and server work must additionally be recorded by the future gateway, not inferred from logical charges.

`LookupBudget(limit=100000)` supports one active reserve/charge/close token. A denied upper-bound reservation stops the query's enumeration permanently before any callback; even if F would have been small, that F is unavailable before the count and is not guessed. `sample_ranks(F,k,rng)` uses exact arbitrary-size integers and O(k) space. The exhaustive toy proof checks each C(4,2) subset appears twice among12 equal-probability RNG branches; a separate1:3 fanout proof checks all four global ranks. Prefix zero weights and a10^40 rank space are covered without full candidate materialization.

`star_graph(tables)` returns connected states and directed single-base extensions in canonical order. For r=5, r+(2^(r-1)-1)=20 states and (r-1)+(r-1)*2^(r-2)=36 edges. `estimate_query(query,bases,probe,trace,n=1000,budget=None,check=...)` visits each directed edge at most once, records skipped/replaced states and complete expansion traces, returns states plus exact prediction/budget/error status, and never invokes a DB. An admission-only stop may retain a full completed state; an in-flight error always gives ERROR_NULL even if a previous full state remains. A complete zero is ZERO_SAMPLE. There is no traditional fallback.
