# Original DBEst Flights 1D routing implementation plan

> Agentic execution: use the executing-plans and test-driven-development workflows task by task in the current original project. ROOT requested the existing branch/workspace; do not create a worktree or spawn agents.

Goal: independently route the still-unimplemented 1D-compatible Flights queries through the pinned original DBEstPy public API, preserving the frozen76 calls and fixed20K retained-row selection. This phase implements code and pure/micro fake tests only. It authorizes no actual source audit over the full sample, categorical scan, fitting, KDE integration, PostgreSQL or Java.

Architecture: three new modules compose pure route/catalog/projection contracts, a separately approved fresh original-engine worker and a strict stdlib read-only artifact auditor. No existing `full_dbest*.py`, official source, model, input or old receipt may change. No multidimensional rectangle-integral extension is implemented. Source: already sealed DBEstPy2220a937b5eef358eb42a715da328915048b7250 and the exact12 public Flights SQL plus the original prefilter SQL in DeepDB upstream655ada13a043a4226a239b0c0a65bcdefef87a02.

Files and interfaces:

- `code/full_dbest_flights_routes.py`: exact12 SQL/support identities; four route specifications; `build_catalog(rows,probability,expected_rows)` using only category/prefilter membership and aggregate non-NULL counts; `make_jobs(selected,catalog)` preserving fixed row IDs; signed product projection and separate taxi components; SQL-NULL-safe external difference; pure independent Gaussian/LR moment oracle and numerical checks.

- Corresponding three `code/tests/test_full_dbest_flights_routes*.py` files contain pure integers, rows and fake API outcomes only in this phase.

Information budget: a future ROOT-approved single pass through the sealed retained sample may count each route's original category prefilter/group membership and each aggregate's non-NULL members before numerical fitting. `Nhat=count/p`; Bernoulli metadata variance is `count*(1-p)/p^2`, with the corresponding SE and a note that this uncertainty is not a full query CI and is not independent of the selected20K subsample. No target full-stream COUNT/SUM/AVG/value enters category counts, cohorts, feature construction, fitted-model binding or original API invocation. The inherited old76-call auditor can read its old truth for integrity and old metadata validation during preflight. That legacy proof is an evidence-plan dependency; its answer/result hashes are excluded from the new scientific training identity. The new independent evaluation receives target values only after the new raw job/query predictions are sealed. All truth groups absent from the metadata/fixed fit sample remain missing. CSV bytes and text fields are necessarily read and decoded; the category scanner does not numerically parse, multiply or accumulate aggregate values. A golden scanner saves only rows at the preexisting selected IDs, with no redraw. Physical generated CSV NULL encoding is not silently guessed: ambiguous empty-string fields are explicitly rejected; pure row fixtures separately verify actual `None` handling.

Null and numerical rules: any NULL product operand gives NULL and is excluded from that product cohort. Taxi SUM components use their own non-NULL IDs/Nhat; missing, failed, NULL or nonfinite child results propagate an unavailable difference, never zero. Zero-fit groups are unavailable. Every nonempty group, including singleton/constant groups, is sent to the original fit API; real failures remain recorded. Native SUM/AVG outputs are returned as predictions only after same-model Gaussian/LR analytic checks; analytic values are oracle-only and never substituted. The pinned1D kernel is Gaussian bandwidth1, original LR, original units. The old validated numerical adapter still has a10000-uniform-breakpoint limit; a wide product span is an explicit numerical-budget gap, not an excuse to silently rescale data or replace KDE/integration.
