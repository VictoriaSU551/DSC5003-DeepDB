# 来源、路径与复现说明

## 已有工作与新增成果
作者提供核心算法、基准查询与官方真值。组员建立初始固定依赖、兼容性适配和下载/训练/评估流程。本阶段新增本机样本量/种子实验、PostgreSQL 对照、全量计数核验、查询案例及中英文材料，并有 AI 辅助编写和执行。种子 1 的 1M 结果与组员早期结果一致，不是新的精度突破。

## 如何复核现有结果
先运行本目录的 verify_contribution.py，只读取已发布的小结果文件，不需要原始数据或模型。对实际模型重新预测，需要另行准备数据、模型及对应依赖；本次上传不包含这些大文件。

## 如需重跑完整实验
不要直接运行 code_snapshot 中会操作数据库或启动窗口的归档文件。先克隆独立实验目录，按根 README 准备 Python 3.8.20、固定依赖及完整 IMDb 数据，再审阅对应历史说明。
- repeat_seeds.py 原本位于 DeepDB/code，依赖 maqp.py 的 --seed 和 verify_results.py 的 --output-root；两项已有文件改动在 patches/seed_support.patch，未应用于本次分支。
- postgres_baseline.py 和 recompute_joblight_truth.py 原本位于 DeepDB/code；数据库二进制和凭据在项目父目录 tools/postgresql。需要明确设置本地 DEEPDB_PG_HOME 并使用独立数据库，不能使用公开副本中的历史绝对路径占位符。
- joblight_exact_count.py 是受限的精确 SQL 变换，只支持已验证的 title 内连接星形查询和单表数字筛选。三个单元测试可独立运行；它不实现 RSPN。
- 历史训练和查询结果路径保留在 JSON 中作出处说明，部分路径已脱敏，不是可直接粘贴运行的命令。源码/模型的历史 SHA256 是原件指纹；本次发布版文件指纹在 MANIFEST.csv。

## 计数核验的具体范围
69 条原 SQL 直接成功，ID 59 原查询先后触发时间与临时文件上限，最后通过等价分组计数得到 9,537,310,863。按 title 分别精确统计各筛选后子表的行数、乘积后求和，无统计独立性假设。先与 ID 0、14、34、57 的原 SQL 实际结果交叉验证。不要声称所有 70 条原 SQL 都直接执行成功。所有计数与官方参考一致，所以历史估计误差指标不变。
